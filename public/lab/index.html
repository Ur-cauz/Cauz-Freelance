                How it is built

                Containerised
                Every service runs in its own Docker container, so one failure stays contained and updates are routine.
                Backed up daily
                Automatic backups run every night and a restore test proves they work.
                Separate copies
                Backups are also copied to USB drives that live apart from the server.
                Watched 24/7
                Metrics and alerts notify the owner as soon as something looks wrong.
                Private by design
                Admin tools are not on the public internet, and this page shows names and numbers only.
